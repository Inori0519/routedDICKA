# Manuscript

`main.tex` is the current article, including Appendices A-E. Its bibliography
is `references.bib`; external images are included from `figures/` as PNG files.
There is no separate supplementary manuscript or compiled article PDF.

The computational implementation in the repository is the one used for the
existing figures: low-dimensional composite statistics certify secrecy, and
each receiver's full ternary record determines error correction. It is not
the later full-ternary complete-table scan.

The five rate figures are identical to their counterparts in
`outputs/figures/`. The remaining included image illustrates the binary SRQ
witness tradeoff in Appendix B; it is not an entropy-rate calculation.

`generated/` contains supporting exports from the original workflow. They are
kept for compatibility with its checks, but are not inputs to this combined
article. Running the numerical workflow does not replace `main.tex`.
